# Flowlark 个人工作台视觉改造设计

## 目标

将已经迁移到 React 19 与 Ant Design 6 的 Flowlark 前端统一为“柔和均衡工作台”风格。改造覆盖全部 React 页面，以个人 AI 工作台设计文件中的低饱和绿色、雾灰、轻卡片、细描边和清晰状态为主，同时保留 Flowlark 原有产品对象、工作流与无障碍要求。

成功后的界面应一眼可识别为安静、清透、适合长期使用的个人工作台，而不是营销页或传统重型企业后台。

## 设计决策

### 视觉方向

- 使用白色、冷雾灰和低饱和绿色构成主视觉。
- 页面背景为浅灰，侧栏、顶部栏和弹层可使用带边框的轻微半透明表面。
- 主体卡片使用 12px 圆角、细边框和低强度阴影；按钮和输入框使用 8px 圆角。
- 正文保持 14px，页面标题 20px，工作台问候语 28px，指标数字 36px。
- 状态同时使用文字与颜色，不以颜色作为唯一信息来源。
- 不使用大 Hero、紫蓝渐变、暗色终端风、装饰性大图或卡片嵌套卡片。

### 规范优先级

1. 本设计说明负责 React 迁移后的视觉落地。
2. 用户提供的《个人 AI 工作台视觉设计规范》负责视觉语言和 `--pw-*` token。
3. 仓库 `DESIGN.md` 与 `design-system/flowlark/MASTER.md` 继续负责 Flowlark 产品对象、导航、文案、状态和无障碍基线。
4. 旧文档中的 Vue 3、Arco Design Vue 技术约束由已确认的 React 19、Ant Design 6 迁移结果替代。

## 页面架构

### 应用外壳

- 桌面端使用 240px 固定侧栏和 64px 顶栏。
- 侧栏顶部显示 Flowlark 品牌与当前工作区，主导航按个人工作台、项目、需求、迭代、交付组织；草稿箱、回收站和设置保持为辅助入口。
- 顶栏展示当前页面上下文、可用的全局搜索入口和运行状态。没有真实能力的控件不做成可点击按钮。
- 主内容区最大宽度为 1440px，页面外边距桌面 32px、平板 24px、手机 16px。
- 低于 768px 时侧栏收进抽屉，顶栏保留菜单、品牌和必要操作；内容改单列。

### 个人工作台

- 顶部使用 28px 问候语和简短今日摘要，不使用营销式首屏。
- 第一行展示项目、需求、迭代和交付四个指标。
- 主体采用 8+4 分栏：左侧展示继续推进和近期内容，右侧展示当前状态与下一步入口。
- 数据继续来自现有项目、需求、迭代和交付接口，不增加后端依赖。

### 列表页

- 项目使用轻量项目卡，突出名称、基线、版本数量和更新时间。
- 需求、迭代等数据密集页面保留 Ant Design 表格，不为了卡片化牺牲扫描效率。
- 搜索、筛选和主操作与页面标题对齐；移动端允许工具栏换行，表格横向滚动。
- 空状态提供明确下一步；加载状态使用与内容结构一致的骨架屏或 Ant Design loading 状态。

### 详情页与版本工作台

- 详情页使用一个主信息表面和后续无嵌套的内容区，减少重复卡片边框。
- 页面标题区提供返回路径，避免详情页形成操作死角。
- 版本工作台保留预览、规格说明和变更三个 Tab；Tab 使用文字与绿色下划线，不使用胶囊主导航。
- 原型预览保持稳定高度和清晰边框，规格正文使用 15px 字号与更宽松行高。

### 设置与辅助页

- 设置页按运行状态、基础配置等组展示，保持只读字段和开关的真实状态。
- 草稿箱、回收站和 404 页使用同一套空状态、列表行和返回导航。

## 组件与 Token

### Token 策略

- 在全局样式中定义设计文件的 `--pw-*` primitive 与 semantic token。
- 现有 `--fl-*` token 作为语义兼容层映射到 `--pw-*`，避免为了换肤重写业务组件。
- Ant Design `ConfigProvider` 映射品牌色、背景、文本、边框、圆角、字体和组件高度。
- 数字和版本号启用 tabular figures；代码、路径和标识继续使用等宽字体。

### 共用组件

- `AppShell`：桌面侧栏、移动抽屉、顶部栏和内容容器。
- `PageHeader`：返回入口、标题、说明和页面级操作。
- `MetricCard`：指标名称、数值和简短上下文。
- `State`：加载、空数据和错误占位。
- Ant Design Card、Table、List、Tag、Button 和 Form 通过主题与全局类统一，不另造平行组件库。

## 交互与可访问性

- 所有可点击表面提供 180–240ms 的 hover、active 和 focus-visible 反馈。
- 图标按钮必须有 `aria-label` 或 Tooltip。
- 键盘焦点使用绿色 2px 轮廓和 2px 偏移。
- 支持 `prefers-reduced-motion`，降级非必要动画与平滑滚动。
- 主操作、危险操作和状态颜色语义保持稳定；危险操作不使用绿色。
- 页面加载、空数据和 API 错误必须有可见反馈，表单错误保留在字段附近。

## 数据与错误处理

- 不修改 API 路径、请求结构或后端数据模型。
- 页面继续独立加载当前所需数据；个人工作台并行读取已有列表接口。
- 单项接口失败不阻断其他指标显示；失败区域展示可重试或明确说明。
- 不引入尚未实现的 AI 自动执行、全局命令或发布能力。

## 响应式

- `>= 1024px`：240px 侧栏，四列指标，主内容 8+4 分栏。
- `768px–1023px`：侧栏可保持或缩窄，指标两列，主内容按空间降为单列。
- `< 768px`：抽屉导航，单列卡片，16px 页面边距，操作区换行，表格横向滚动。
- 固定格式元素使用稳定高度、`minmax()`、`aspect-ratio` 或明确网格轨道，避免加载和标签变化引起跳版。

## 验收与测试

- `npm run build` 成功，无缺失导入和 TypeScript/JSX 构建错误。
- 桌面 1440×900 和移动 390×844 下检查个人工作台、项目、需求、详情与版本工作台。
- 页面不存在横向溢出、文字遮挡、按钮截断、卡片套卡片或导航错位。
- 导航选中态、移动抽屉、项目跳转、列表搜索、弹窗开关和 Tab 切换可操作。
- 浏览器控制台无新增 React 错误；后端未启动时允许出现已识别的 API 网络错误，但页面必须有稳定的可见状态。

## 范围边界

- 本轮覆盖全部已迁移的 React 页面和共用样式。
- 不恢复或重写仍保留在仓库中的旧 Vue 页面。
- 不补齐框架迁移中尚未实现的复杂业务功能，不切换到完整 Umi/Ant Design Pro 运行时。
- 不修改后端、CLI、数据文件格式、Git 行为或用户已有的无关工作区改动。
