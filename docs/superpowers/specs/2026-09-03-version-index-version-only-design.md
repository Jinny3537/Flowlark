# 版本索引仅展示版本号设计

## 目标

精简项目版本页左侧的版本索引行，使每行只展示版本号，例如 `v6`、`v5`。用户仍可通过列表选择版本，并在右侧查看完整版本详情。

## 范围

### 删除

- 版本索引行中的版本标题。
- 创建人和创建时间。
- “新”“上次看到这里”等阅读标记。
- 基线、生命周期状态和评审状态标签。
- 仅服务于上述内容的列表行样式和组件内派生变量。

### 保留

- 搜索框及其现有匹配范围和持久化行为。
- 版本索引的现有宽度和行高。
- 版本号、选中态、悬停态和焦点态。
- 点击选择、上下方向键切换以及移动端打开详情抽屉的行为。
- 右侧版本详情及页面其他区域的全部信息和操作。

## 页面行为

版本索引中的每一行继续使用按钮和 `listbox` / `option` 语义，但视觉内容和无障碍名称都只包含版本号。选择版本后，现有详情区或移动端详情抽屉照常展示完整信息。

本次不压缩侧栏宽度或行高，避免改变页面整体布局，也避免搜索框提示文字因宽度变化而被截断。

## 实现边界

仅修改：

- `web/src/pages/ProjectVersions.tsx`：把版本行渲染收敛为版本号，并删除列表循环中不再需要的状态计算。
- `web/src/pages/ProjectVersions.module.css`：把版本行改为单列布局，删除只服务于标题、元数据和状态标签的样式。

不修改过滤模型、API、服务端数据结构或其他页面。

## 验证

- 静态检查确认列表循环不再渲染标题、元数据、阅读标记或状态标签。
- 运行项目版本模型测试，确认现有搜索与排序逻辑不受影响。
- 运行前端生产构建，确认 TypeScript、CSS Modules 和依赖引用有效。
- 页面验收确认桌面端和移动端列表行只显示版本号，点击和键盘选择仍可用。
