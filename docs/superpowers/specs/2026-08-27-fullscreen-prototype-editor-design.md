# 全屏原型文字编辑页设计

## 背景

版本工作台当前把原型预览和版本文档放在同一分屏内。“在线编辑”直接在左侧预览 iframe 中启用浏览器编辑模式，可用空间受分屏和工作台工具栏限制，也没有可见的文字格式控制。用户希望参考提供的实时预览界面，在当前标签页进入独立的大画布页面，对整个原型进行文字与基础格式编辑。

## 已确认决策

- 从版本工作台进入当前标签页中的独立编辑路由。
- 编辑页采用顶部身份栏、全宽原型画布、底部悬浮工具栏。
- 支持文字内容、加粗、斜体、下划线、字号、文字颜色和左/中/右对齐。
- 不支持区块拖动、布局调整、图片替换或可视化组件搭建。
- 点击“完成”统一保存并返回版本工作台。
- 直接退出且存在未保存修改时必须确认。
- 源码、文件和 URL 替换继续保留在版本工作台的“修改原型”入口。

## 目标

- 给原型文字编辑提供尽可能大的稳定画布。
- 让用户能看见并直接使用常见文字格式能力。
- 保持原型脚本与 Flowlark 工作台数据的跨端口隔离。
- 复用现有版本权限和 HTML 保存链路，不新增存储格式。
- 对未保存退出、保存失败和只读版本给出明确反馈。

## 非目标

- 不建设通用低代码页面搭建器。
- 不提供拖拽、缩放、图层、组件树、图片上传或样式属性面板。
- 不新增自动保存、多人协作、撤销历史或草稿恢复服务。
- 不改变版本基线、离线包、原型下载或源码替换行为。
- 不把任意原型内容复制到工作台同源 DOM 中。

## 页面与路由

新增路由：

```text
/projects/:slug/versions/:versionNo/edit
```

该路由在 `AppShell` 外渲染，页面占满浏览器视口。版本工作台的“在线编辑”按钮跳转到该路由；原工作台不再在分屏 iframe 内切换编辑模式。

### 顶部编辑栏

- 左侧显示“实时编辑”、项目名称和版本号。
- 脏状态显示“未保存”；保存期间显示“正在保存”。
- 右侧提供“退出编辑”按钮。
- 点击退出：无修改时直接返回；有修改时弹窗确认“放弃修改 / 继续编辑”。

### 原型画布

- 使用现有预览端口的 `?edit=1` HTML，继续通过 sandbox iframe 隔离。
- iframe 占据顶部栏之外的全部可用空间。
- 编辑桥接脚本对可编辑文字元素显示轻量虚线轮廓；当前目标使用更明显的主色轮廓。
- 编辑轮廓、桥接脚本和临时属性在序列化保存前必须移除，不能污染原型文件。

### 底部悬浮工具栏

- 固定在视口底部中央，不跟随原型内部滚动。
- 提供：加粗、斜体、下划线、字号、文字颜色、左对齐、居中、右对齐。
- 右端提供“完成”主按钮。
- 按钮具备可访问名称、键盘焦点和至少 44px 的点击高度。
- 窄屏时工具栏允许横向滚动，不挤压或遮断功能。
- 本次不提供参考图中的 AI 文字修改，因为它超出已确认的文字与基础格式范围。

## 编辑通信协议

工作台和预览原型跨端口，父页面不能直接访问 iframe DOM。扩展现有预览桥接脚本，通过 `postMessage` 完成编辑。

### 页面到 iframe

```json
{ "type": "flowlark:edit-command", "id": "...", "command": "bold", "value": null }
```

命令只允许固定白名单：

- `bold`
- `italic`
- `underline`
- `fontSize`
- `foreColor`
- `justifyLeft`
- `justifyCenter`
- `justifyRight`

桥接脚本保存最近一次有效文本选区。工具栏获得焦点后，iframe 先恢复该选区，再执行白名单命令。任意其他命令被拒绝。

### iframe 到页面

- `flowlark:edit-ready`：编辑桥已启用。
- `flowlark:edit-dirty`：文字或格式发生修改。
- `flowlark:edit-state`：返回当前选择处的格式状态，供工具栏显示按下状态。
- `flowlark:edit-command-result`：返回命令是否执行成功。
- 现有 `flowlark:edit-html`：返回清理后的完整 HTML，用于保存。

父页面只接受来自当前 iframe `contentWindow` 的消息，不读取其他窗口消息。

## 数据流

1. 编辑页并行加载项目、版本和运行状态。
2. 根据现有 `canEditStructure` 规则判断是否可编辑。
3. 可编辑时加载预览端口的 `?edit=1` iframe；不可编辑时显示说明并提供返回工作台。
4. 用户在 iframe 中修改文字，桥接脚本发送脏状态和格式状态。
5. 用户点击工具栏，父页面发送白名单格式命令，iframe 恢复选区并执行。
6. 用户点击“完成”，父页面请求清理后的 HTML，并调用现有 `replaceHtml` API。
7. 保存成功后返回版本工作台；工作台重新加载预览时看到新内容。

## 状态与异常

- 项目、版本或健康状态加载失败：显示错误状态和重试、返回入口。
- 版本不存在、已废弃、已成为锁定基线或工作区只读：不加载可编辑 iframe，说明不可编辑原因。
- 桥接脚本未就绪：格式按钮和“完成”禁用，显示加载状态。
- 格式命令失败：保留当前内容并显示错误消息。
- 读取编辑 HTML 超时：不提交 API，提示重试。
- 保存失败：留在编辑页，保留 iframe 内的修改和脏状态。
- 页面刷新或关闭浏览器且存在未保存修改：使用 `beforeunload` 提示。
- 点击页面内“退出编辑”且存在未保存修改：使用 Flowlark 确认弹窗。

## 视觉与无障碍

- 使用现有 Flowlark 颜色、圆角、阴影和字体 token。
- 顶部栏和悬浮工具栏保持高对比，画布本身不加装饰性容器。
- 图标按钮必须带 `aria-label` 和 Tooltip；按下状态使用 `aria-pressed`，不能只依赖颜色。
- 主要按钮和文字颜色满足现有主题对比度。
- 工具栏不拦截 iframe 的文本选区；桥接脚本负责恢复选区。
- `prefers-reduced-motion` 下关闭非必要位移和过渡。

## 测试与验收

### 服务端桥接

- `?edit=1` 注入编辑桥，普通预览不注入。
- 编辑桥只接受白名单格式命令。
- 序列化结果不包含桥接脚本、编辑样式和临时目标属性。
- HTML 缺少标准 `body` 或 `html` 结束标签时仍可注入并返回内容。

### 前端

- 编辑入口生成并进入正确的独立路由。
- 编辑路由不显示主导航侧栏和普通工作台页头。
- 只读或不可编辑版本不能进入有效编辑状态。
- 加粗、斜体、下划线、字号、颜色和三种对齐命令能发送到当前 iframe。
- 修改后显示未保存状态；直接退出出现确认。
- 点击完成成功保存并返回；失败时停留且内容不丢失。
- 桌面和窄屏下页面无整体横向溢出，工具栏功能可滚动访问。
- 浏览器控制台无新增运行时错误。

### 回归

- 普通预览、标注反馈、离线预览和“修改原型”抽屉仍可使用。
- 现有版本工作台、预览服务和 HTML 替换 API 测试通过。
- Web 构建通过。
