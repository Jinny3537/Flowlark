# 原型入口型项目首页设计

## 背景

当前项目首页使用多字段管理表格，突出需求数、逾期数、优先级、状态和更新时间。该结构适合项目治理，但 Flowlark 的项目入口更核心的任务是让用户快速进入某个产品的原型版本管理。管理指标占据主视觉后，项目名称、最新原型和进入原型工作区的动作反而被弱化。

本次采用已经通过可视化对比确认的“A · 原型入口卡片”与“A2 · 最新版本摘要”方向，把项目首页重新定位为原型工作区启动页。

## 目标

- 项目首页首先回答“我要进入哪个产品的原型管理”。
- 每个项目卡片直接展示最新可用原型版本摘要。
- 整张卡片可点击并支持键盘进入项目版本管理页。
- 项目编辑保持可达，但不与主入口竞争。
- 无版本项目明确引导用户进入项目创建首个版本。

## 非目标

- 不在项目首页加载真实 HTML 原型缩略图或 iframe。
- 不删除需求数、逾期数、优先级等后端项目数据。
- 不修改项目版本页、版本工作台或新建版本流程。
- 不改变项目、版本、基线和需求的存储格式。
- 不新增最近访问记录、收藏、排序偏好或分页 API。

## 页面定位与结构

### 页头

- 眉题：“原型项目”。
- 标题：“选择项目，进入原型管理”。
- 说明：“查看最新原型版本，并进入项目版本工作区。”
- 右侧保留“新建项目”主按钮。

### 筛选

首页只保留两类查找能力：

- 项目名称/代码搜索。
- 项目状态筛选：全部、进行中、已归档。

移除优先级筛选。优先级、需求数和逾期数不再出现在首页主内容中，避免把入口页重新变成管理报表。

### 卡片网格

- 1440px 及以上：三列。
- 1024px 至 1439px：两列。
- 1023px 以下：单列。
- 卡片高度由内容决定，同一行保持一致。

## A2 项目卡片

### 卡片头部

- 项目代码，使用等宽字。
- 项目状态，使用标准圆点加文字：进行中/已归档。
- 右上角“更多操作”按钮，仅包含“编辑项目”。

### 项目身份

- 项目名称为卡片主标题。
- 不展示项目描述、需求数、逾期数或优先级。

### 最新版本摘要

项目存在非废弃版本时展示：

- 最新版本号。
- 最新版本标题。
- 版本展示状态：编辑中、当前基线或历史版本。
- 版本更新时间。
- 项目版本总数。
- 当前基线版本号；无基线时显示“未设置”。

最新版本定义为：按现有版本时间线排序规则选出的最新非废弃版本。废弃版本不作为首页代表原型，但仍计入项目版本总数。

项目不存在非废弃版本时展示：

- “暂无可用原型版本”。
- “进入项目后创建首个版本”。
- 版本总数；若仅存在废弃版本，仍显示真实总数。

### 主入口

- 卡片主要内容区域是一个语义按钮，点击或按 Enter 进入 `/projects/:slug`。
- 底部持续显示“进入原型管理 →”。
- “更多操作”按钮位于主按钮之外，避免嵌套交互元素。
- 点击“编辑项目”只打开现有编辑弹窗，不触发页面跳转。

## 数据契约

项目列表和项目详情沿用现有接口，并新增派生字段：

```json
{
  "latestVersion": {
    "versionNo": "v2.4",
    "title": "订单批量操作",
    "display": {
      "key": "DRAFT",
      "label": "编辑中",
      "short": "草稿",
      "color": "gold"
    },
    "updatedAt": "2026-08-26T08:00:00.000Z"
  }
}
```

没有非废弃版本时 `latestVersion` 为 `null`。

服务端使用现有 `rules.sortVersions` 和 `rules.displayStatus` 派生该字段，确保 CLI、HTTP 和前端使用一致规则。项目统计值继续保留，其他页面不会受到影响。

## 状态与异常

- 列表加载、加载失败和无项目继续使用现有 `State` 组件。
- 搜索/筛选无结果时显示“没有匹配的项目”。
- 只读模式禁用新建与编辑，但仍可进入原型管理页浏览。
- 最新版本摘要缺少标题或时间时使用现有可读回退文案。
- 编辑保存成功后刷新卡片数据；失败时保留编辑弹窗和输入。

## 视觉与无障碍

- 使用现有 Flowlark token、字体、圆角和阴影。
- 卡片 hover 只表达可进入性：边框主色化并轻微抬升。
- `:focus-visible` 显示主色轮廓。
- 状态始终使用圆点加文字，不只依赖颜色。
- 版本状态使用文字标签。
- 更多操作按钮提供项目名称相关的 `aria-label`。
- 卡片主按钮的 `aria-label` 包含项目名称和“进入原型管理”。
- 关闭动效偏好下禁用抬升过渡，沿用全局降级规则。

## 测试与验收

### 核心与 API

- 有多个版本时返回最新非废弃版本。
- 最新废弃版本不会成为 `latestVersion`。
- 无非废弃版本时返回 `latestVersion: null`。
- `latestVersion.display` 与现有版本展示状态一致。
- HTTP 项目列表返回相同摘要结构。

### 前端

- 项目搜索仍只匹配名称和代码。
- 状态筛选正常；页面不再出现优先级筛选。
- 整张卡片点击和键盘 Enter 都进入项目版本页。
- 更多操作只打开编辑弹窗。
- 有版本和无版本卡片使用正确文案。
- 1440、1024、768 和 390px 无页面横向溢出。
- 浏览器控制台和页面运行时错误为空。
