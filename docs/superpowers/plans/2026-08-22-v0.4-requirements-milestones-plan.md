# Flowlark v0.4 Requirements and Milestones Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade to Schema 2 and add first-class requirements, milestones, static delivery packages, faceted search, and shared saved views.

**Architecture:** Keep version-to-requirement links single-directional and derive reverse indexes. Treat milestones as editable groups and defer immutable evidence to v0.5 snapshots.

**Tech Stack:** Node.js filesystem APIs, deterministic JSON helpers, existing offline builder, Vue 3, Pinia, Ant Design Vue, Node test runner.
