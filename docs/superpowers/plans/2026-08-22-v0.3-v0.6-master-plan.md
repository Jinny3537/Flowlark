# Flowlark v0.3-v0.6 Master Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Flowlark from v0.2.6 to v0.6.5 with feedback, requirements, milestones, delivery workflows, notifications, macOS distribution, and multi-repository discovery.

**Architecture:** Keep the existing local-first Node.js/Vue/Git architecture. Add focused core modules behind `Hub`, expose them through the existing HTTP and CLI boundaries, and keep tracked facts separate from local caches and macOS Keychain secrets.

**Tech Stack:** Node.js ESM, built-in Node APIs, Vue 3, Pinia, Ant Design Vue 4, Vite, Node test runner, real temporary Git repositories, local mock HTTP services.

## Shared File Boundaries

**Create:**

- `src/core/feedback.js`: feedback payloads, anchors, Markdown, local drafts.
- `src/core/importer.js`: HTML source/title extraction and SSRF-safe URL import.
- `src/core/secrets.js`: environment and macOS Keychain secret access.
- `src/core/integrations/issues/*.js`: GitHub, GitLab, Gitee adapters.
- `src/core/requirements.js`: requirement entities, derived state, reverse index.
- `src/core/milestones.js`: milestone persistence and validation.
- `src/core/snapshots.js`: immutable delivery snapshots.
- `src/core/exporter.js`: requirement/milestone static delivery packages.
- `src/core/notifications.js`: webhook templates, adapters, retry queue.
- `src/core/impact.js`: traceable change-location impact suggestions.
- `src/core/migrate.js`: Schema 1 to 2 migration and rollback.
- `src/core/workspaces.js`: local workspace registry and cross-repository index.
- `src/core/updater.js`: release manifest and checksum verification.
- `src/core/mirror.js`: read-only fast-forward-only synchronization.
- `scripts/package-macos.sh`: deterministic `.app` packaging.

**Modify:**

- `src/core/service.js`: orchestration only; delegate domain behavior.
- `src/core/store.js`: path primitives and Schema 2 version fields.
- `src/core/repo.js`: Schema 2 initialization and migration gate.
- `src/core/config.js`: non-secret integration, notification, update, and mirror settings.
- `src/server/routes.js`: REST resources for all new domains.
- `src/cli/index.js`, `src/cli/help.js`, and focused command modules.
- `web/src/api.js`, `web/src/router.js`, `web/src/store.js`, `web/src/App.vue`.
- `web/src/style.css`: shared responsive states and design tokens only.
