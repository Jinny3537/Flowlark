# Flowlark v0.5 Delivery and Notifications Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add webhook notifications, safe templates, annotation deep links, review states, immutable delivery snapshots, and traceable impact suggestions.

**Architecture:** Complete tracked business transactions first, then emit best-effort notification events into an idempotent local retry queue. Keep snapshots immutable and derive impact suggestions from historical changelog sources.

**Tech Stack:** Node.js built-in HTTP/fetch/crypto APIs, macOS Keychain adapter from v0.3, Vue 3, Ant Design Vue, Node test runner.
