# Flowlark v0.6 Distribution Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a macOS app bundle with bundled Node, first-run workspace setup, verified update downloads, read-only mirrors, cross-repository search, and complete recovery documentation.

**Architecture:** Keep the Web workbench as the only product UI. Add a thin launcher and local workspace registry around the existing server, and keep mirror/update operations isolated from tracked repository data.

**Tech Stack:** macOS app bundle, shell packaging script, Node.js built-in APIs, system Git/SSH, macOS `security` and `osascript`, Vue 3, Node test runner.
